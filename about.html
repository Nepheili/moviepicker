О проекте

MoviePicker помогает быстро выбрать фильм на вечер. В основе — открытый датасет Top Movies с данными TMDB: почти 10 000 фильмов с описаниями, рейтингами, популярностью и жанрами.

Что умеет сайт

  • 🎭Топ-20 самых популярных фильмов в каждом из 19 жанров
  • ⭐Фильтр по минимальному рейтингу и три вида сортировки
  • 🔍Живой поиск по названию и описанию
  • 🎲Случайный фильм, если не хочется выбирать

Как считается топ

Один фильм может относиться к нескольким жанрам — он участвует в рейтинге каждого из них. Внутри жанра фильмы упорядочены по популярности TMDB (по убыванию). Если в жанре меньше 20 фильмов, показываются все.

  • Рейтинг — средняя оценка зрителей (Vote_Average) от 0 до 10.
  • Популярность — индекс TMDB, отражающий текущий интерес к фильму.
  • Голосов — число зрителей, оценивших фильм.

Технологии

Чистые HTML, CSS и JavaScript без фреймворков. Данные готовит скрипт build_data.py, который превращает CSV в data/movies.json и data/genres.json. Сайт работает офлайн; из интернета подгружаются только постеры фильмов.
